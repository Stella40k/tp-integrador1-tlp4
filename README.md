# TP Integrador — Taller de Lenguaje de Programación IV

**Dominio:** A — Mesa de ayuda (Tickets)
**Base de datos:** PostgreSQL + Sequelize
**Organización del backend:** Carpeta por tipo de archivo

## Integrantes

- Bernard, Stella — [tu-usuario-de-github]

## Descripción

Aplicación web básica de Mesa de Ayuda desarrollada con arquitectura en capas y TypeScript estricto. Implementa los patrones de diseño Singleton, Observer, Factory y Adapter para la gestión y notificación de estados de tickets.

## Requisitos previos

- Docker y Docker Compose
- Node.js (v18 o superior)
- Git

## Cómo ejecutar el proyecto

1. Clonar el repositorio:
   ```bash
   git clone <url-del-repositorio>
   cd tp-integrador-tlp4
   ```
